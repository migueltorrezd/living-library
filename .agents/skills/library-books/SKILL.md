# Author a Living Library book

Resolve paths from the repository root containing `package.json` and `AGENTS.md`.

1. Read `AGENTS.md`, `docs/authoring/agent-workflow.md` and `docs/authoring/export-and-register.md`.
2. For missing Blender or MCP, follow `docs/authoring/blender-setup.md`. Preserve existing application state and configuration. Verify a read-only scene query before editing.
3. Research the requested edition, record uncertainty and acquire permitted source assets with provenance. Never silently pay for assets or generation.
4. Author in a working copy, preserve the named hierarchy, then stage and verify an export.
5. Install reviewed assets and catalogue records; inspect the app at desktop and mobile sizes.
6. Report the edition, verification results, reconstruction limits and local versus published state.

Included sources are finished editable models. Replacing one image cannot accurately manufacture every possible binding. Adapt geometry and materials to the evidence.
